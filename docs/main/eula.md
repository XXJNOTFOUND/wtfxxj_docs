# 规则与服务说明

本页用于说明服务器的基本服务原则。详细游玩规则请阅读 [服务器规则](/rules)。

## 隐私与账号

- 服务器会尽力保护玩家账号与隐私信息。
- 请不要在公共聊天中发布他人真实姓名、手机号、身份证号、聊天记录、截图等隐私内容。
- 账号申诉、改密、绑定变更等问题，请优先通过服务器公告指定的渠道联系管理员。
- 管理员在处理违规、纠纷、诈骗、破坏等问题时，可能会查看必要的服务器日志。

## 社区发言

请遵守法律法规与社区基本礼仪，不发布违法、色情、暴力、诈骗、隐私泄露、恶意引战等内容。

## 违规处理

处理结果会根据证据、影响范围、主观恶意和历史记录综合判断。玩家可以通过官方渠道申诉。

::: tip
为了更快处理问题，请在反馈时提供：玩家名、时间、坐标、截图或录像、相关聊天记录。
:::
